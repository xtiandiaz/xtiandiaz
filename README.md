My current focus is on the dev. of Web SPAs (Single Page Apps) and PWAs (Progressive Web Apps) preferably using (although not strictly) this stack: [**Vue**](https://github.com/vuejs) (v3, Composition API), [**Pinia**](https://github.com/vuejs/pinia), [**PixiJS**](https://github.com/pixijs) (to enhance and gamify the apps), and [**NodeJS**](https://github.com/nodejs), _entirely with_ `TypeScript`. And using tools such as: [Vite](https://vite.dev/) (to dev. and build the apps), and [Capacitor](https://capacitorjs.com/) (to package them for distribution).

My former focus was first on game dev. using the Unity engine (with `C#`, at companies such as [_Yousician_](https://yousician.com/), and later at native iOS dev. (with `Swift`, UIKit & SwiftUI, at companies such as [_Ōura_](https://ouraring.com/)). However, in the past 1,5 years, lured by the Web’s flexibility, portability, and its modern capabilities, I've been devoting most of my time to the aforementioned stack, and looking for career opportunities to hasten the transition. Plus, the former XP, albeit on different techs were also meant for mobile apps, and thus facilitates and nurtures greatly the transition.

Here's a bunch of early attempts for the sake of my current goals:

# Tiny, custom, kinda frameworks:
- [Vueties](https://github.com/xtiandiaz/vueties): a collection of Vue components shared by several of my tiny Web-apps (listed below), and using the Design Tokens described above.
- [Emerald](https://github.com/xtiandiaz/emerald): for simple WebGL game dev. and prototyping, built on top of PixiJS for rendering and supporting elementary, custom, hand-crafted 2D physics.

# Utilities:
- [Design Tokens](https://github.com/xtiandiaz/design-tokens): a collection of scripts to read the _design tokens_ (icons, colors, text-styles) from a public Figma 'file' using their API, to generate code and assets to consume on your apps. For instance, the [Vueties](https://github.com/xtiandiaz/vueties) use my example.

# Tiny Vue SPAs:
- [Ari](https://github.com/xtiandiaz/ari): to exercise mental math using visual/aural modes.
- [Recetario](https://github.com/xtiandiaz/recetario): a take on offering digestible instructions (heh, pun intended) and ingredient listings for cooking (and misc. DIY) recipes.
- [Lexi](https://github.com/xtiandiaz/lexi): an elementary card-based mini-game to review random words that have been collected (while reading and trying to expand vocabulary) in multiple languages.

And there's a bunch more in mind, and a few already in the making, to be listed here eventually.
